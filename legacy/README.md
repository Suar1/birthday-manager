# Original Node birthday manager

The independent `master` history contained an earlier Node.js application. Its original source is preserved in `node-birthday-manager/`; the repository root remains the current Flask birthday manager.

This directory is a historical copy, not the Docker deployment entry point. The merge preserves both histories without replacing the Flask application or its data directories.

Runtime SMTP credentials from the original branch are intentionally excluded, matching main's prior removal of user configuration. The original commit remains available in the merged history.
